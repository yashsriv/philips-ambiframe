I want to set up an android TV screensaver applicationh displays fine art. The primary idea behind it which will differentiate it from the native screensaver (which can also display fine art) is that it will be running on a phillips ambilight tv and hence when the screensaver starts, I want it to turn off the ambilight. When the screensaver is dismissed, ambilight should start up again.

For this purpose, there is a complicated setup for ambilight API access which I want as a setup step in the app itself.
